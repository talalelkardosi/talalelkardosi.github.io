## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## GitHub Pages

The GitHub Actions workflow builds the portfolio as a static site and publishes
`dist/client` whenever changes are pushed to `main`. In the repository's
**Settings → Pages**, set the build and deployment source to **GitHub Actions**.
The site is configured for the domain root at
`https://talalelkardosi.github.io/`.
